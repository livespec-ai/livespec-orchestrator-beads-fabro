## Definition of Done assertions derived from that statement

- The broker runs outside the agent stage's process tree and holds the forge credential itself, so the agent stage's environment, files and processes do not.
- A request to the broker to merge, ready or edit the run's pull request is refused.
- A request that claims to come from the pr stage is refused, because the broker takes the stage it serves from the workflow that launched the node and never from anything the agent can set.
- The broker posts a new comment only on the run's own pull request and uploads proof assets only to the run's own proof asset store.
- A proof_verify turn that posts a Proof of Done record through the posting primitive and uploads its proof assets through the proof asset store has the broker post the record on the run's pull request and upload the assets.
- A review turn that posts its findings record as a comment on the run's pull request has the broker post the comment, while the turn's publication actions remain refused.
- Among the workflow's command nodes, publication-capable credentials are available only to publish_draft, pr_refresh and pr, each only within its own publication step, and to the command steps whose own contract requires them to preserve a run's work; no other command node holds them.
- Each of publish_draft, pr_refresh and pr pushes, opens, readies or arms the run's pull request as specified, and no LIVESPEC_AGENT_PUBLICATION_DENIED refusal is raised.
- A command node that preserves a run's work, such as the needs_human preservation step, keeps the credentials its own contract requires.
- In every agent stage of the implement-work-item workflow, the agent's environment, files and processes hold no forge token.
- In every agent stage of the implement-work-item workflow, the agent's environment, files and processes hold no GitHub App credential and no key from which one can be minted.
- A raw git push or a direct forge API request from an agent stage fails without changing origin or the run's pull request.
